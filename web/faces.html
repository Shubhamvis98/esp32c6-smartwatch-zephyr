face.json reference

Top level: name, desc, background ("#RRGGBB"), background_image (240×280 image), elements (drawn in order).

Every element: type, x, y (offset), align: center, top, bottom, left, right, top_left, top_right, bottom_left, bottom_right (screen 240×280).

  • text: text, font (14 16 20 24 36 48), color, width, text_align (left center right), letter_space
  • rect: w, h, color, radius, opacity (0–255), border_width, border_color
  • image: src ("logo.png")
  • arc: value (steps battery seconds minutes hours), size, width, color, bg_color, start_angle, end_angle (0° = 3 o'clock, clockwise), rounded
  • bar: value, w, h, color, bg_color, radius
  • hand: hand (hour minute second), cx, cy (pivot on screen, default 120,140); line hand: length, tail, width, color; image hand: src drawn pointing to 12, pivot_x, pivot_y (default bottom centre), under 48 KB

Text tokens: {HH} {H} hour (12/24 h setting), {mm}, {ss}, {AMPM}, {day} Monday, {ddd} Mon, {DDD} MON, {D} {DD} day of month, {month} January, {mmm} Jan, {MMM} JAN, {MM} month number, {YYYY}, {steps}, {goal}, {battery}
